# WHAT IS SPEECHMAX?

SpeechMax is software designed to help the user practice speaking by alerting them with a tone whenever the word “like” is detected. 

This project is made possible with openWakeWord: https://github.com/dscripka/openWakeWord

# DEPENDENCIES

```pip install playsound==1.2.2```

```pip install openwakeword playsound==1.2.2 pyaudio numpy```
